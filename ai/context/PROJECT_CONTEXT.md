# ThermoCore Project Context

## Purpose

This file gives an AI a compact understanding of ThermoCore before any task begins.

## Project identity

ThermoCore is a reusable, component-based thermodynamic simulation platform.

The first reference application is ThermoCore.AWG, a portable atmospheric water generator simulator.

## Main goals

- Reusable thermodynamic components
- Explicit mass and energy conservation
- Deterministic simulation
- Web-accessible simulation
- AI-assisted development
- Open-source readiness

## Current primary application

ThermoCore.AWG models:

- ambient moist air;
- photovoltaic generation;
- solar air heating;
- Peltier cooling and heat recovery;
- silica-gel adsorption and regeneration;
- condensation;
- airflow and fan behavior;
- battery and power management;
- recirculation;
- supervisory control.
