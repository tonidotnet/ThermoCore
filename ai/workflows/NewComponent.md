# Workflow: New Component

1. Create or select an issue.
2. Identify physical domains.
3. Write engineering specification.
4. Define ports, parameters and state.
5. Define balances.
6. Define numerical method.
7. Define diagnostics.
8. Define unit and integration tests.
9. Request Architect review.
10. Request Physicist review.
11. Request Numerical Engineer review.
12. Implement only after specification is ready.
13. Update graphs and progress.
