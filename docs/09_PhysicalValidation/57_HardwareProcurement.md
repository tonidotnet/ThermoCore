# R8 Hardware Procurement

## Priority 0 --- cooling hardware: buy nothing

Use the existing Mirabelle E24 and Siguro SGR-DH-P300W first.

## Preferred documented bare TEC

**Advanced Thermal Solutions ATS-TEC40-39-004** - 40×40×3.9 mm; - 15.4 V
max; - 6 A max; - Qmax 53 W; - ΔTmax 68 °C; - resistance 2.05 Ω; - TME
lists single-piece ordering and manufacturer documentation.

This is preferred for analytical-model validation because provenance is
stronger than anonymous marketplace TECs.

## Higher-power comparison

**ATS-TEC40-35-005**: 40×40×3.5 mm, 15.4 V, 8 A, Qmax 68.8 W, ΔTmax 68
°C, 1.51 Ω; buy only if stock is available.

## Low-cost Hungarian alternatives

HESTORE lists individual TEC1-12704 (\~48 W class), TEC1-12706 (\~51 W
class) and TEC1-12708 (\~85 W class). Good for mechanical/destructive
experiments, but weaker manufacturer provenance.

## Recommended order

1.  instrumentation;
2.  run existing appliances;
3.  one ATS-TEC40-39-004 for reference bench work;
4.  optionally 1--2 cheap TEC1-12706 modules for fixture development.
