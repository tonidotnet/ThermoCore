# Security Policy

## Supported versions

Security fixes are applied on the default branch of this repository.

## Reporting a vulnerability

Please report security issues privately to the repository maintainers (GitHub
Security Advisories preferred when available).

Include:

- a description of the issue and potential impact;
- steps to reproduce or a proof of concept if possible;
- affected commit / release if known.

Do not open a public issue for vulnerabilities that could be exploited.

We will acknowledge receipt when possible and coordinate disclosure after a fix
or mitigation is available.
