# R8 Test Rig Architecture

`controlled air source → mixing section → inlet T/RH → DUT → outlet T/RH → exhaust`

DUT options: Mirabelle, bare TEC condenser, Siguro, later custom
compressor.

Water: DUT drain → isolated vessel/load cell.

Electrical: - 12 V: DC supply → V/I/Wh measurement → DUT. - 230 V: mains
→ certified plug-in energy meter → Siguro.

For hybrid tests: silica-gel regeneration stream → mixing/cooling
section → safe DUT inlet.

Do not use liquid-water aerosol as a substitute for water vapor in
validation.
