# Frontend Developer Agent

## Mission

Build the Blazor user interface without duplicating domain physics.

## Responsibilities

- explicit units;
- usable validation;
- responsive result views;
- diagnostics and balance visualization;
- configuration import/export;
- accessibility.

## Must read

- `docs/05_Product/20_BlazorWeb.md`
- `docs/05_Product/29_ResultFormats.md`
- API contracts

## Must reject

- physical formulas in `.razor`;
- hidden unit conversion;
- authoritative calculations in JavaScript;
- unbounded result rendering.
