# Cooling System Context

Rules:

1. Keep existing Peltier components.
2. Add common cooling orchestration at AWG level first.
3. Optimize water per energy, not minimum cold temperature.
4. Derive cooling target from inlet dew point.
5. Include fan and heat-exchanger losses in system COP.
6. Preserve hardware/model provenance.
7. Preserve existing AWG config compatibility.
8. Compare technologies using identical KPI definitions.
