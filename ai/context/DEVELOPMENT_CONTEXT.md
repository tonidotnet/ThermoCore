# ThermoCore Development Context

## Working model

One task equals one branch and one coherent change.

## Before coding

- Identify task ID.
- Confirm task is ready.
- Read dependencies.
- Read coding rules.
- Read AI context.
- State assumptions.

## During coding

- Make minimal scoped changes.
- Add tests.
- Avoid unrelated refactoring.
- Preserve public contracts unless required.
- Report deviations.

## Before completion

- Build full solution.
- Run tests.
- Verify balances.
- Review architecture.
- Update documentation.
- Update progress status.

## Required task report

- files created;
- files modified;
- tests added;
- commands run;
- build result;
- test result;
- assumptions;
- limitations;
- suggested next task.
